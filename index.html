FLAGSHIP PROJECT

mcp-mesh: The Dynamic MCP Gateway

The official open-source gateway for Claude Desktop, Cursor, Antigravity, and Cline. It transparently aggregates dozens of upstream MCP servers while indexing tools with BM25 keyword matching and serving full JSON schemas lazily on demand.

  • Zero External Dependencies: 100% Python standard library. No pip install headaches.
  • Two-Tier Lazy Routing: Exposes mesh_search_tools and mesh_invoke_tool.
  • Stdio Multiplexer: Transparently routes child processes with zero client reconfiguration.
