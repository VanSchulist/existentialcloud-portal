The Problem

Why static MCP schemas break coding agents

1. Turn-0 Context Exhaustion

Each connected tool adds ~220 tokens of JSON schema. Connecting 15 tools across GitHub, Postgres, and Slack dumps 3,300 to 15,000+ tokens into the system prompt on every single turn, costing dollars per developer session before work starts.

2. "Lost in the Middle" Degradation

Flooding the LLM context with hundreds of parameter signatures distracts frontier models (Claude 3.5 Sonnet, GPT-4o). High schema density increases tool hallucinations, invalid argument structures, and skipped system instructions.

3. Fragmented Workstation Configs

Developers configure separate MCP servers inside Claude Desktop, Cursor, and Antigravity. Managing duplicate subprocesses spawns zombie child processes and slows down IDE startup times.
